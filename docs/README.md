# Thesis and research document index

## Current thesis

- `thesis/current/Latest-July-26-Thesis-Paper.docx` — canonical thesis paper
- `thesis/current/Thesis (Comments_Suggestions) - Synced.docx` — synchronized
  routing/comments companion

The paper files were reorganized only. Their prose was not silently rewritten.

## Archive

`thesis/archive/` contains previous DOCX/PDF revisions. Git history is retained,
but these files are not the current thesis source.

## Research material

- `research/audits/` — architecture reviews, benchmark verification,
  methodology notes, and implementation proposals
- `research/diagrams/` — conceptual-framework HTML diagrams
- `../experiments/` — reproducible classifier/retrieval experiment code

Historical analyses may describe superseded behavior. The deployed architecture
and current terminology are defined by the repository README, the versioned
prediction trace, and the current benchmark manifest.

## Defense material

`defense/` contains checklists, mock-defense questions, demo notes, prompts, and
presentation drafts.

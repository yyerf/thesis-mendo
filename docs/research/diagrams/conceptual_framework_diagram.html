Five-Stage Cascaded Pipeline for Multilingual OTC Symptom Detection and Recommendation

STAGE 1 User Interaction
User types symptom description on touchscreen kiosk in Bisaya, Tagalog, English, or code-switched combinations. Age is optionally provided.

Input Examples

  • "masakit akong ulo ug gi-ubo ko"
  • "I have headache and runny nose"
  • "may lagnat ako, 25 years old"

Supported Languages

  • Cebuano / Bisaya
  • Filipino / Tagalog
  • English
  • Taglish / Code-Switched
  • Jejemon / Leetspeak
raw text + age
STAGE 2 Triage & Safety Screening
Input scanned against 8 medical emergency categories using multilingual regex patterns before any symptom extraction occurs.

8 Red-Flag Categories

  • Chest Pain
  • Difficulty Breathing
  • Blood in Stool
  • Blood in Vomit

 

  • Severe Allergic Reaction
  • High Fever (≥40°C)
  • Seizure
  • Loss of Consciousness
RED FLAG DETECTED
⚠️ CONSULT
A DOCTOR
OTC recommendations suppressed
no red flags → proceed
STAGE 3 Symptom Detection
Two-path extraction: rule-based dictionary runs first; semantic model activates only when dictionary returns zero results.
PRIMARY

Step 1 — Rule-Based Dictionary

307 curated phrases across 13 symptom labels. Includes negation handling, fuzzy rescue, cough-type qualification, and contrastive boundary logic.

FALLBACK

Step 2 — Semantic Embeddings

MiniLM-L12-v2 model with 118 anchor sentences. Fires only when dictionary returns ∅. Cosine similarity threshold = 0.65.

Precision-first switching: dictionary results are trusted; semantic only activates as fallback

detected symptom labels
STAGE 4 Hybrid Orchestration & Safety Filters
Consolidates detections, resolves conflicts, and applies safety guards before passing clean symptom set to scoring engine.

Safety Filters

  • 7 explicit negation functions
  • 11 lexical keyword gates
  • Red-flag symptom suppression
  • Score-rank top-N selection

Context Assessment

  • Cough type clarification
  • Diarrhea context (OLDCARTS)
  • Headache context (OLDCARTS)
  • Stomach ache context (OLDCARTS)
clean symptom set + age + context
STAGE 5 Recommendation & Presentation
Scores 23 OTC medications (18 brands) against detected symptoms. Enforces age restrictions and contraindication rules. Displays ranked results with dosage guidance and safety warnings.

Scoring Engine

  • Symptom–drug match scoring
  • Brand merge (highest score)
  • Age-based filtering (min_age)
  • Paracetamol overlap detection

Output Safeguards

  • Opposing mechanism warnings
  • Severity ≥ 8 → pharmacist referral
  • No match → "consult pharmacist"
  • ASG source attribution
